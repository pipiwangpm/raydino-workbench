# RayDino 测试标定工作台

Web 交互原型，包含设备连接、关节标零、硬件控制、遥控器、SN 编订和工程调试。

在线访问：https://pipiwangpm.github.io/raydino-workbench/

## 使用
直接打开 index.html，或用静态服务器启动本目录。无需安装依赖。

- 连接：Wi-Fi、蓝牙、局域网 IP。
- 标零：15 个关节、保存及验证。
- 硬件控制：录音、回放、摄像头、ToF、风扇与 LED。
- 遥控器：方向控制、功能键与头部控制。
- 工程调试：参数、CSV、OTA、离线升级、固件烧录及日志。

## 快捷键
W/S 前后，A/D 左右转，Q/E 左右平移，方向键等同 WASD，空格停止。
1–9 对应功能按键，I/K 头部上下，J/L 头部左右。按钮显示键位。

## 原型范围
设备连接、遥测、动作、升级与烧录均为模拟流程，尚未连接真实机器人；不会操作电脑网络或硬件。数据只保存在当前浏览器，可导出记录。CSV 和报告保留模拟数据标识。

## 文件
index.html 为入口，app.js、engineering.js、workbench.js、remote.js 实现交互；style.css、workbench.css 提供样式。


## 蓝牙配网与页面分区
首次使用仅提供蓝牙连接。连接机器人后输入 Wi-Fi 名称和密码，通过蓝牙下发配置，待机器人入网后进入工作台。密码不写入浏览器存储、日志或导出记录。
页面分为连接与配网、测试与遥控、工程维护。运动参数和机身控制放在遥控器内，设备名称移至工程维护的设备设置。
开发版运动参数：vx 默认 0.2 m/s，范围 0–0.6，步长 0.02；vyaw 默认 0.5 rad/s，范围 0–1.5，步长 0.05；持续时间默认 1 s，范围 0.2–20，步长 0.1。
配网仍为原型演示：不会配对真实蓝牙、发送真实 Wi-Fi 凭据或修改网络设置。正式接入需要设备端蓝牙配网协议、入网状态回执和通信适配。


## 关节明细与控制布局
关节明细使用固定关节标识（如 left_hip_yaw），仅显示角度、标零状态及单关节标零操作。温度列已移除。数字硬件 ID 对照尚未提供，不按列表顺序推定 ID。已移除手柄配对入口，机身控制放在方向遥控区域上方。


## 暂定数字关节 ID
按用户要求为原型指定固定数字 ID：左腿 1–5（髋偏航、髋侧摆、髋俯仰、膝、踝），右腿 6–10（同序）；颈部俯仰 11、头部俯仰 12、头部偏航 13、头部侧摆 14、嘴部 15。映射按关节标识显式定义，不随列表排序变化。它是产品原型的暂定映射，不是已核实的硬件总线 ID；后续接入时可替换 prototypeJointIds。导出报告注明映射类型为 prototype。


## 第一视角预览
摄像头打开弹出第一视角预览，展示代码绘制的低机位实验室示例画面与轻微镜头动画；不申请浏览器摄像头权限、不连接真实视频。右上角、底部关闭按钮与 Esc 均关闭摄像头预览，断开连接时同步清理。新增 camera.js。


## 功能按键精简
坐下和起立合并为「坐下/起立」切换键，快捷键 1，对应 sit_toggle。移除独立起立键（快捷键 2）和轮滑键（快捷键 9），其他快捷键保持不变。
